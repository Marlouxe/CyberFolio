// what's in an update

What does an update really contain?

An update is usually a mix of several things, and the most important one is often the least visible.

01
Critical

Security fixes (patches)

Software contains millions of lines of code. Flaws (called vulnerabilities) are regularly discovered in it. When a flaw is identified, vendors publish a fix. If you don't install it, the flaw stays open. Hackers exploit these known flaws: it's much easier than finding new ones.

02
Useful

Performance & stability

Updates also fix bugs, make the software faster and more stable. Your device generally runs better after an update.

03
Minor

New features

Yes, sometimes too. But it's often the least important part of a security update.

// timeline of a flaw

The life cycle of a security flaw

Understanding this cycle helps grasp the urgency of updates.

01

A flaw is discovered in a piece of software (by a researcher or a hacker)

02

If it's a researcher, they quietly alert the software vendor

03

The vendor develops a fix and releases an update

04

The flaw becomes public and every hacker in the world now knows about it

05

Attacks targeting this flaw explode in the following hours or days

Updated
Protected

✕

Not updated

⏱

The window between the release of an update and an attack exploiting the flaw is often a few hours to a few days. The longer you wait, the more vulnerable you are.

// putting it into practice

How to do it without it being a chore?

A

Enable automatic updates

🪟 Windows: Settings → Windows Update → Turn on automatic updates
🍎 Mac: System Settings → Software Update → Check "Keep my Mac up to date"
📱 Smartphone: Automatic updates are usually enabled by default
B

Schedule your restarts

Many systems let you schedule restarts overnight, when you're not using your device. Set up this option so you're never interrupted.

C

Make it a weekly ritual

If you prefer to stay in control, get into the habit of checking for updates once a week. Make it a ritual, like checking your emails on Monday morning.

// myth busting

Misconceptions to forget

✕ "Updates slow down my device"
✓

It's sometimes true in the first minutes after installation, while the device adjusts. In the long run, updates generally improve performance. If your device is slow after an update, it usually clears up after a restart.

✕ "My device is new, it doesn't need updating"
✓

The age of the device has nothing to do with it. A security flaw can affect software released last week. The update fixes the problem, whatever the age of your device.

✕ "I have nothing important, nobody would want to hack me"
✓

Hackers aren't necessarily after your data. They may want to use your device to send spam, mine cryptocurrency without your knowledge, or launch attacks against other targets. Your outdated device can be used as a relay without you knowing.

☠
// obsolete software

What about end-of-life software?

Software at "end of life" no longer receives security updates. That's the case for Windows XP, Windows 7, or older versions of Android.

Using such a system is like driving a car without brakes: flaws pile up and no fix will ever come. If you're in this situation, it's strongly recommended to move to a recent, supported version.

Windows XP Windows 7 Android < 10 iOS < 16 macOS < Ventura No more security fixes →
★

Key takeaway in one sentence

Turn on automatic updates today: it's the simplest and most effective thing you can do for your digital security.

Immediate action Settings → Updates → Automatic ✓
